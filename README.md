# Psychopath Web

NextJS framework based web application for interactive map visualization.

## Installation

```bash
npm install
```

## Environment Setup

Copy the example environment file and configure your variables:

```bash
cp .env.example .env
```

Required environment variables:
- `NEXT_PUBLIC_TILE_LAYER_URL` - Tile server URL for map layers

## Running the app

```bash
# development
npm run dev
```

The application will be available at `http://localhost:3000`
